What happens when someone posts a found item

  1. Application Load BalancerReceives the request and sends it to whichever EC2 instance is healthy, checking each one at /health.
  2. EC2Two instances in different availability zones run the Flask app with gunicorn. If one stops, the other keeps the site up.
  3. S3The photo is uploaded to the uploads/ folder of the bucket. The app never stores AWS keys; the EC2 IAM role grants access.
  4. RDS (MySQL)The report is saved in the reports table. The database sits in private subnets and only accepts connections from the web servers.
  5. LambdaThe new object in S3 triggers a function that logs the upload's details (file, size, time) without any server to manage.
  6. CloudWatchCollects the Lambda logs and EC2, load balancer and RDS metrics, shows them on a dashboard, and emails an alarm if CPU goes above 70%.

Around everything

VPC

One private network across two availability zones: public subnets for the load balancer and web servers, private subnets for the database. Security groups chain load balancer → web servers → database.

IAM

Roles for EC2 and Lambda with only the permissions they need, and separate IAM users for each team member instead of the root account.
